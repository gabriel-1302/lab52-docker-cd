# mi-api — Lab 5.2: CI/CD con Docker y GitHub Actions

API REST construida con Node.js y Express, desplegada automáticamente en AWS EC2 mediante un pipeline de CI/CD con Docker Hub y GitHub Actions.

## Endpoints

| Método | Ruta | Descripción |
|---|---|---|
| GET | `/` | Mensaje de bienvenida |
| GET | `/health` | Health check del servicio |
| GET | `/api/items` | Lista de items de ejemplo |
